# Codex Nest

Codex Nest organizes Codex projects into a user-defined hierarchy.

## Language

**Codex Project**:
A project registered in Codex with its own working directory and chats. It is a leaf in the project tree.

**Project Group**:
A named container for projects or other groups. It has no working directory.

**Project Tree**:
A collapsible hierarchy of Codex Projects and Project Groups. The user decides where each item belongs.
