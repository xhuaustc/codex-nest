# Share the chat runtime with Codex Home

Interactive chat inside Codex Nest was considered with a shared Home runtime. Reading the same saved history does not establish shared control of a running turn. On November 18, 2026, the desktop host reported the current local chat as `active` while the accessible local daemon reported the same chat as `notLoaded`.

The project tree now opens the selected conversation directly in Home. The plugin's read-only transcript pane and message-reading tool were removed.
