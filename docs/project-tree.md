# 项目树规格

- 用户从 Codex 桌面左侧栏进入 Codex Nest 的项目管理视图。先通过最小原型验证入口在 Codex 模式下可见且可以打开。
- 视图展示 Codex 已注册的本地和远程项目。创建项目时可选择来源设备、目录和所属分组。远程目录由 Codex 桌面端完成注册。
- 项目树显示真实项目名和用户命名的分组。新项目默认在顶层。项目和分组可移到顶层或分组下。分组不能移到自身或自己的下级。项目是叶节点。
- 可拖动项目名或图标，把项目放在分组行或组内列表中以移入该组，也可移回顶层。悬停在折叠组上会临时展开；取消拖动会恢复临时展开的状态。
- 工作目录只在项目详情中显示。移动项目只更改视图中的父子关系。
- 同级节点按显示名称排序。刷新视图后保留逻辑关系和展开状态。
- 点击项目名进入该项目的聊天列表。点击分组名或分组旁的箭头交替展开和折叠。
- 点击聊天名直接打开 Codex Home 中的原会话。
- 项目聊天列表顶部左侧的「新建聊天」打开该项目的 Codex Home 输入框。多目录项目使用 Primary 目录。
- 「归档项目内聊天」在 Codex 中归档所确认的聊天，保留项目。插件内隐藏的项目和归档的单条聊天可从 Nest 的「归档」列表恢复。恢复隐藏项目时沿用原来的分组。
- 插件支持创建本机 Codex 项目、编辑项目名称和工作目录，以及在 Finder 中打开注册目录。新建时可为项目添加多个现有目录。移除项目仍在原生界面操作。

例如，Platform 和 API 的工作目录可以在不同位置：

```text
工作            用户创建的分组
├── Platform    Codex 项目，可打开
└── API         Codex 项目，可打开
```
