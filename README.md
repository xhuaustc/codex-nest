# Codex Nest

Codex 桌面端的逻辑项目树。分组可以包含项目和子分组，项目是叶节点。选择项目名查看聊天，点击分组名或箭头展开或收起内容。

界面支持简体中文和英文，跟随 Codex 传递给插件的语言设置。宿主未提供语言时，使用网页视图报告的语言。项目、分组和聊天名称保留原文。

点击聊天列表里的条目会直接打开 Codex Home 中的原会话。

在左侧「项目」标题的 `…` 菜单里选择「新建分组」。分组行的 `…` 菜单提供「编辑分组」以更改组名。选择一个项目或分组，再用详情中的「移动到」设置它的上级。布局保存在这个插件视图的本地存储，未归类的项目显示在顶层。

右键点击左侧栏空白处可打开「新建项目」和「新建分组」菜单。

项目行和聊天行的 `…` 菜单可以归档当前条目。打开左侧「项目」标题的 `…` →「归档」可查看和恢复条目。归档只改变 Codex Nest 的列表，恢复项目时会保留原来的分组位置。

左侧「项目」标题旁的 `+` 可以将一个或多个现有目录注册到本机 Codex。选中分组时，新项目会出现在该分组中。项目行的 `…` 菜单提供「编辑项目」和各个工作目录。点击工作目录可在 macOS Finder 中打开。创建和编辑使用桌面自带的 Codex app-server 项目接口，该接口目前是实验性的。

## 安装

在仓库根目录运行：

```sh
codex plugin marketplace add "$PWD"
codex plugin add codex-nest@codex-nest
```

仓库级 [marketplace manifest](.agents/plugins/marketplace.json) 注册了 [Codex Nest 插件](plugins/codex-nest)。本地 MCP Server 需要 Python 3，无第三方依赖。

## 桌面验证

1. 安装插件后，在桌面应用切换到 Codex 模式并新开一个聊天。
2. 检查全局侧栏是否显示 **Codex Nest**。也可打开 [Codex Nest 项目树](codex://plugins/codex-nest@codex-nest/app/logical_projects)。
3. 打开项目树，确认显示本机已注册项目，选择项目后打开一条真实聊天。
4. 新建一个分组，将两个位于不同目录的项目移入分组。重新打开项目树，检查层级和展开状态是否保留。

打开项目树和点击「刷新」时，插件从本机 Codex 读取项目和聊天列表。显式归属优先；未显式分配、且工作目录只匹配到一个注册项目的聊天，也会显示在该项目下。原生聊天查询不可用时，界面会标明正在使用本地索引。

首次渲染使用本地 UI 资源中的项目名称和主目录。桌面端可能缓存这份资源，视图连上 Codex 后会重新读取项目列表和聊天索引。聊天标题不会放进缓存的初始资源。

设计范围见 [项目树规格](docs/project-tree.md)。
